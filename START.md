# Как запустить бота. С нуля, без технических терминов

## Сначала пойми главное

`@SpeakOutEducation_bot` — это **не программа**. Это имя и номер, которые Telegram тебе выдал. Сейчас за этим именем никого нет, поэтому бот молчит.

Программа, которая будет отвечать, написана и лежит в твоём репозитории на GitHub. Её нужно **запустить на каком-нибудь компьютере**. Пока она работает — бот отвечает. Выключил компьютер — бот замолчал.

Вот и всё, что происходит. Дальше — три шага.

---

# Шаг 1. Получить три ключа

Это займёт минут пять. Всё бесплатно, банковская карта нигде не нужна.

Заведи пустой файл в Блокноте и складывай ключи туда по мере получения.

### Ключ 1 — токен бота

1. Открой Telegram, найди **@BotFather**
2. Напиши ему `/mybots`
3. Выбери **SpeakOutEducation_bot**
4. Нажми **API Token**
5. Скопируй строку — она выглядит так: `1234567890:AAF-xxxxxxxxxxxxxxxxxxxxxxxxxxxx`

### Ключ 2 — Gemini (это «мозг» бота)

1. Открой **https://aistudio.google.com/apikey**
2. Войди через свой Google-аккаунт
3. Нажми **Create API key**
4. Скопируй строку — она начинается на `AIza...`

### Ключ 3 — Groq (распознаёт твою речь)

1. Открой **https://console.groq.com/keys**
2. Зарегистрируйся (можно через Google)
3. Нажми **Create API Key**
4. Скопируй строку — она начинается на `gsk_...`

> **Сразу покажи ключ, как только создал.** Groq и Google показывают его только один раз. Не скопировал — создавай новый, ничего страшного.

# Шаг 3. Запустить

## Если у тебя Mac

1. Нажми **Cmd + Пробел**, напиши `Терминал`, нажми Enter. Откроется чёрное окно — это нормально.

2. Напиши в нём `cd ` (обязательно с пробелом в конце), **затем перетащи мышкой папку с программой прямо в окно терминала**. Путь подставится сам. Нажми Enter.

3. Напиши и нажми Enter:

   ```
   bash setup.sh
   ```

4. Дальше скрипт всё сделает сам. Когда спросит ключи — вставляй их по одному (**Cmd + V**, затем Enter).

   > При вставке в терминал текст может не появиться на экране. Это защита, а не ошибка. Просто жми Enter.

## Если у тебя Windows

1. Открой папку с программой в Проводнике

2. Нажми **правой кнопкой** на пустом месте внутри папки → **Открыть в терминале** (или «Открыть окно PowerShell здесь»)

3. Напиши и нажми Enter:

   ```
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```

4. Дальше скрипт всё сделает сам. Когда спросит ключи — вставляй по одному (**Ctrl + V**, затем Enter).

# Если что-то пошло не так

| Что видишь | Что делать |
|---|---|
| `command not found: python3` | Установи Python: https://www.python.org/downloads/ . На Windows при установке **обязательно** поставь галочку *Add Python to PATH* |
| `bash: setup.sh: No such file` | Терминал находится не в той папке. Вернись к пункту 2 и перетащи папку заново |
| Скрипт написал «бот будет отвечать ТЕКСТОМ, без голоса» | Не встал ffmpeg. Бот работает, просто без голоса. Mac: `brew install ffmpeg`. Windows: `winget install Gyan.FFmpeg`. Потом перезапусти скрипт |
| Бот не отвечает в Telegram | Проверь, что окно терминала открыто и в нём нет красных строк. Скорее всего неверный токен — перепроверь шаг 1 |
| В терминале красное `Unauthorized` | Токен неправильный или отозван. Возьми новый у @BotFather |
| `resource exhausted` | Кончилась дневная бесплатная квота Gemini. Сбросится ночью |

Если ничего не помогло — **скопируй последние 20 строк из терминала и покажи мне**. По тексту ошибки я скажу точно, в чём дело.

# «А чтобы работал всегда, даже когда мой компьютер выключен?»

Тогда программу надо поселить не на своём компьютере, а на чужом, который никогда не выключается. Такой можно получить бесплатно и навсегда — это описано в [deploy/README.md](deploy/README.md).

Но это следующий этап. **Сначала запусти у себя и убедись, что бот тебе нравится.** Переселить его потом — дело пятнадцати минут.
