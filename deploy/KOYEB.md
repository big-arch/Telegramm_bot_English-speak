Симптом, по которому это видно: заходишь в панель Koyeb, а она пустая — кнопки создания сервиса нет, только баннер про Mistral.

[RENDER.md](RENDER.md) описывает то же самое на Render: так же через браузер, так же GitHub + Docker + Supabase, так же без карты и без терминала.
