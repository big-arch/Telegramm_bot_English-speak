# SpeakOut — [@SpeakOutEducation_bot](https://t.me/SpeakOutEducation_bot)

Разговорный английский в Telegram. Ты записываешь голосовое — ИИ-собеседник отвечает голосом, а в конце разговора даёт разбор.

**Работает на бесплатных тарифах.** Нужен один ключ помимо токена бота, выдаётся мгновенно без карты, дальше ничего не стоит.

> 👉 **Не хочешь держать компьютер включённым?** → [deploy/RENDER.md](deploy/RENDER.md) — только браузер, без терминала.
> 👉 **Хочешь просто попробовать у себя?** → [START.md](START.md) — пошагово, без терминов.
> Другие варианты хостинга — [deploy/README.md](deploy/README.md).

## Чем отличается

Мы разобрали Speak, ELSA, Praktika, Loora, TalkPal и Gliglish. У всех, кто делает ИИ-собеседника, повторяется одна и та же жалоба: **«разговоры зацикливаются и остаются поверхностными»**. У Speak отдельно — «нет системы долгосрочного удержания».

Причина у всех одна: **ИИ не помнит**. Каждый разговор начинается с нуля. Вчера ты двенадцать раз ошибся в артиклях — сегодня собеседник об этом не знает.

SpeakOut построен вокруг памяти:

| Что | Как это сделано |
|---|---|
| **Память между сессиями** | `users.memory_summary` — сжатая заметка, которую модель переписывает после каждого разговора и читает перед следующим |
| **Журнал ошибок → практика** | Каждая правка размечается категорией; повторяющиеся категории подкладываются в следующие разговоры |
| **Правки не перебивают** | Во время разговора — ничего. Разбор в конце, максимум 3 ошибки, отобранные по тяжести и готовности уровня |
| **Скорость речи по уровню** | A1 звучит на 0.82×, C2 на 1.1×. Снимает жалобу «ИИ говорит слишком быстро» |
| **Заточка под русскоязычных** | Артикли, аспект, `I am agree`, оглушение конечных согласных, `ship/sheep` |
| **Слова из реальных разговоров** | Карточки создаются из того, что ты действительно сказал, а не из списка |
| **Разговор по своей фотографии** | Присылаешь фото — собеседник видит его и спрашивает о нём. Он и сам может попросить показать что-нибудь |

## Быстрый старт

```bash
# ffmpeg обязателен — без него не будет голоса
sudo apt install ffmpeg        # или brew install ffmpeg

make install
cp .env.example .env           # BOT_TOKEN и GROQ_API_KEY — всё
make setup                     # миграции + темы разговоров
make run
```

Ключ: [console.groq.com/keys](https://console.groq.com/keys). Бесплатно, без карты.

Есть ключ [Gemini](https://aistudio.google.com/apikey)? Поставь `LLM_PROVIDER=gemini` — диалог станет заметно живее, тоже бесплатно. Ключ Groq всё равно нужен: распознавание речи идёт через него.

Чтобы бот работал круглосуточно, а не пока включён ноутбук — [deploy/README.md](deploy/README.md).

## Провайдеры

Всё меняется одной переменной. Дефолт — бесплатный.

| Роль | Бесплатно (по умолчанию) | Платная альтернатива |
|---|---|---|
| Диалог и разбор | `LLM_PROVIDER=groq` — Llama 3.3 70B, тот же ключ что и для речи | `gemini` — Flash, тоже бесплатно, качество выше; `anthropic` — Claude Opus 5 |
| Распознавание речи | `STT_PROVIDER=groq` — Whisper v3 turbo, ~8 часов аудио/день | `openai` |
| Зрение (фото) | `VISION_PROVIDER=auto` — Gemini, если есть ключ, иначе Groq | `off` — тогда бот просит описать фото словами |
| Синтез речи | `TTS_PROVIDER=edge` — нейроголоса Microsoft, без ключа | `openai`, `elevenlabs` |
| База | `sqlite+aiosqlite` — локальный файл | Supabase / Postgres |

При старте бот печатает, что он использует и сколько это стоит:

```
providers: llm=groq stt=groq tts=edge db=sqlite mode=polling
billing: everything on free tiers — this run costs nothing
```

Если ключ для выбранного провайдера не задан, бот падает сразу при запуске с понятным сообщением, а не через час внутри обработчика.

## Что внутри

```
bot/
├── __main__.py          композиция: config → preflight → dispatcher → polling
├── personas.py          5 персонажей: голос под каждого провайдера, характер, скорость
├── texts.py             все русские тексты интерфейса
├── data/topics.py       16 тем разговора с целью для каждой
├── db/                  модели, репозитории, upsert под SQLite и Postgres
├── middlewares/         сессия БД, загрузка юзера, троттлинг
├── handlers/            start · conversation · review · progress · settings
└── services/
    ├── llm.py           два вызова: собеседник и оценщик
    ├── prompts.py       промпты — отдельно от провайдеров
    ├── backends/        groq (free) · gemini (free) · anthropic
    ├── stt.py           Whisper с таймкодами по словам (groq | openai)
    ├── vision.py        разговор по фотографии (gemini | groq)
    ├── tts.py           edge | openai | elevenlabs + ffmpeg + скорость
    ├── fluency.py       беглость речи из таймкодов — бесплатно, без модели
    ├── feedback.py      отбор правок: что показать, а что промолчать
    ├── srs.py           SM-2
    ├── conversation.py  оркестрация хода
    └── speak.py         отправка голосом + кэш file_id
```

### Как устроен один ход

```
голосовое → Whisper с таймкодами по словам
          → беглость считается из таймкодов (локально, бесплатно)
          → ответ собеседника  ┐ параллельно —
          → разбор ошибок      ┘ ждём медленный, а не сумму
          → запись хода + ошибок + новых слов (одна транзакция)
          → TTS голосом персонажа → кэш по хешу → отправка
```

Два вызова модели разделены намеренно. У собеседника и у проверяющего противоположные инстинкты: первый хочет продолжать разговор, второй — остановиться и исправить. Один промпт на обе роли даёт бота, который либо перебивает постоянно, либо не исправляет никогда.

Отбор правок живёт в `feedback.py`, то есть **в коде, а не в промпте** — значит, педагогику можно тестировать и менять, не перебирая формулировки.

Разбор ошибок требует, чтобы модель процитировала ошибку дословно; всё, что не находится в реплике буквально, отбрасывается кодом. На бесплатной модели это защита важнее, чем на топовой.

## Лимиты бесплатного тарифа

Квоты считаются на аккаунт, а не на пользователя бота. Groq на бесплатном тарифе даёт около 8 часов аудио в сутки и тысячи запросов к модели — этого хватает на несколько десятков активных людей.

Если упрёшься в лимит модели: `GROQ_ASSESSOR_MODEL=llama-3.1-8b-instant` поднимает дневной потолок в разы, потому что у младшей модели он заметно выше.

`FREE_DAILY_TURNS=40` по умолчанию не даёт одному человеку выжечь дневную квоту до обеда.

Расход пишется в `usage_days` по каждому пользователю с первого дня, так что момент «пора платить» видно по данным, а не по счёту.

## Ограничения, о которых честно

- **edge-tts — неофициальный эндпоинт** Microsoft. Работает и держится годами, но гарантий нет. Если сломается — `TTS_PROVIDER=openai` или `elevenlabs`, остальное не меняется.
- Голосовые асинхронные: ответ приходит за 2–4 секунды, это не живой звонок.
- Bot API не даёт скачать файл больше 20 МБ — отсюда лимит в 120 секунд на сообщение.
- Если Groq не вернёт таймкоды по словам, метрики беглости просто замолчат — разговор продолжит работать.
- SQLite — один процесс. Для второй реплики нужны Postgres и `REDIS_URL`.
- Whisper иногда «поправляет» грамматику говорящего. Мы гасим это промптом, но не полностью.
- Аватарки персонажей пока текстовые: эмодзи, имя, акцент, описание характера. Картинок в `assets/personas/` ещё нет.
